# Лабораторна робота №3

## Тема

Використання кастомних жестів у React Native та стилізація інтерфейсу мобільного застосунку.

## Мета

Навчитися працювати з жестами користувача у мобільному застосунку, реалізувати взаємодію через різні типи жестів та застосувати сучасні підходи стилізації у React Native.

## Інструкція запуску

1. Клонувати репозиторій:

```bash
git clone https://github.com/rock7492/MobileLabsRN2026.git
cd MobileLabsRN2026/lab3
```

2. Встановити залежності:

```bash
npm install
```

3. Запустити проєкт:

```bash
npx expo start --android
```

## Опис реалізованого функціоналу

Застосунок реалізовано у вигляді гри-клікера з використанням жестів:

### Підтримувані жести

- одиночне натискання (Tap) — +1 очко;
- подвійний клік (Double Tap) — +2 очки;
- довге утримання (Long Press, 3 секунди) — +5 очок;
- перетягування (Pan) — переміщення об’єкта + бонус;
- свайп (Fling) — випадкова кількість очок;
- масштабування (Pinch) — бонусні очки.

### Сторінка завдань

- відображення списку завдань;
- прогрес виконання у відсотках;
- автоматичне оновлення статусу;
- приклади завдань:

 - виконати 10 натискань;
 - зробити 5 подвійних кліків;
 - утримати об’єкт 3 секунди;
 - виконати свайпи;
 - змінити розмір об’єкта;
 - набрати 100 очок.

### Сторінка налаштувань

- перемикання світлої/темної теми;
- скидання прогресу через модальне підтвердження.
