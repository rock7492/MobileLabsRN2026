# Лабораторна робота №5

## Тема

Побудова навігації у React Native із використанням бібліотеки Expo Router.

## Мета

Ознайомлення з концепцією file-based маршрутизації в мобільних застосунках.

## Інструкція запуску

1. Клонувати репозиторій:

```bash
git clone https://github.com/rock7492/MobileLabsRN2026.git
cd MobileLabsRN2026/lab5
```

2. Встановити залежності:

```bash
npm install
```

3. Запустити проєкт:

```bash
npx expo start --android
```

## Опис реалізованого функціоналу

У застосунку реалізовано каталог комп’ютерних комплектуючих із використанням Expo Router та file-based маршрутизації. Структура навігації побудована через папку `app`, де кожен файл відповідає окремому маршруту. Екрани розділені на дві групи: публічні `(auth)` для входу та реєстрації і захищені `(app)` для роботи з основним функціоналом.

Система авторизації реалізована через глобальний контекст `AuthContext`, який зберігає стан користувача та його роль. Доступ до основної частини застосунку отримує лише авторизований користувач. Адміністратор має розширені можливості керування товарами.

Каталог товарів відображається у вигляді списку з використанням `FlatList`. Кожен товар містить назву, ціну, опис та зображення, яке підтягується з локальних файлів застосунку. При натисканні відкривається сторінка деталей товару, реалізована через динамічний маршрут, де відображається повна інформація.

Реалізовано кошик, який прив’язаний до конкретного користувача через `CartContext`. Користувач може додавати товари до кошика, змінювати їх кількість, видаляти або очищати кошик. Відображається загальна кількість товарів і підсумкова вартість замовлення.

Додано функціонал оформлення замовлення. При натисканні кнопки "Оформити замовлення" користувач отримує повідомлення про успішне оформлення, після чого кошик очищається.

Роль адміністратора реалізована через окрему панель керування. Адміністратор може додавати нові товари, редагувати існуючі та видаляти їх із каталогу. Усі зміни одразу відображаються в інтерфейсі.

## Висновки

1. Яким чином за допомогою Expo Router реалізується перенаправлення неавторизованого користувача?

Перенаправлення реалізується через компонент `<Redirect />`, який повертається з layout або сторінки при певній умові. Найчастіше перевіряється стан авторизації, і якщо користувач не має доступу, він автоматично перенаправляється на інший маршрут.

2. У чому полягає різниця між використанням компонента <Link> та метода router.push()?

`<Link>` забезпечує декларативну навігацію, яка описується прямо в JSX і використовується для переходів через інтерфейс. `router.push()` виконує імперативну навігацію, коли перехід викликається програмно після виконання певної логіки або дії.

3. Як працюють динамічні маршрути в Expo Router і як отримати передані параметри?
Динамічні маршрути створюються через файли з параметрами в квадратних дужках, наприклад `[id].jsx`. Значення параметра передається через URL і отримується за допомогою хука `useLocalSearchParams()`, який повертає об’єкт із усіма переданими параметрами.

4. Чому стан авторизації доцільно зберігати у глобальному контексті (React Context), а не в локальному стані компонента?

Глобальний контекст дозволяє використовувати стан авторизації в будь-якій частині застосунку без передачі даних через props. Це забезпечує централізоване керування станом, спрощує структуру коду і дозволяє легко контролювати доступ до різних екранів.

5. Для чого використовуються групи маршрутів (folderName) і як вони впливають на URL-адресу?

Групи маршрутів використовуються для організації структури проєкту і логічного розділення екранів. Назви таких папок у круглих дужках не додаються до URL, тому вони не впливають на кінцеву адресу маршруту.
