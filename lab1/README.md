# Лабораторна робота №1

## Тема

Використання Expo для створення найпростішого додатку React Native. Знайомство з основними компонентами.

## Мета роботи

Навчитися створювати та налаштовувати проєкт у середовищі Expo, ознайомитися зі структурою React Native застосунку та опанувати навички роботи з базовими компонентами.

## Опис проєкту

Розроблений мобільний застосунок складається з трьох основних екранів:

- **Головна сторінка** — відображає список новин з заголовками, датами та описами.
- **Фотогалерея** — реалізує сітку зображень у вигляді плитки.
- **Профіль користувача** — містить форму реєстрації та відображення збережених даних користувача.

У застосунку використано:

- базові компоненти React Native (`View`, `Text`, `Image`, `ScrollView`, `TextInput`);
- навігацію між екранами через React Navigation;
- стилізацію через `StyleSheet`.

## Інструкція запуску

### 1. Клонування репозиторію

```bash
git clone https://github.com/rock7492/MobileLabsRN2026.git
cd MobileLabsRN2026/lab1
```

### 2. Встановлення залежностей

```
npm install
```

### 3. Запуск проекту

```
npx expo start --android
```

## Опис основних способи запуску

### Android Emulator

Використовується для запуску застосунку на віртуальному Android-пристрої.
- не потребує фізичного смартфона;
- дозволяє тестувати різні версії Android;
- зручно для розробки;
- споживає ресурси комп'ютера.

### Фізичний Android-пристрій

Запуск через Expo GO на реальному смартфоні.
- найточніше відображає реальну роботу застосунку;
- дозволяє перевірити UX та продуктивність;
- потребує підключення до однієї мережі.

### Expo Web

Запуск застосунку у браузері.
- швидкий запуск;
- зручний для перевірки інтерфейсу;
- поведінка може відрізнятись від мобільної версії.
