# Лабораторна робота №2

## Тема

Побудова вкладеної навігації та оптимізація відображення великих списків у React Native із використанням компонентів FlatList та SectionList.

## Мета

- ознайомлення з принципами навігації у мобільних застосунках React Native;
- вивчення архітектури вкладеної навігації;
- набуття практичних навичок використання Drawer Navigator та Stack Navigator;
- засвоєння методів передачі параметрів між екранами;
- опанування ефективного відображення великих наборів даних;
- вивчення механізму віртуалізації списків;
- практичне застосування компонентів FlatList та SectionList;
- формування навичок оптимізації продуктивності мобільних застосунків.

## Інструкція запуску

Клонувати репозиторій:
```
git clone https://github.com/rock7492/MobileLabsRN2026.git
cd MobileLabsRN2026/lab2
```
Встановити залежності:
```
npm install
```

Запустити проєкт на Android:
```
npx expo start --android
```

## Опис функціоналу

У застосунку реалізовано вкладену навігацію за допомогою Drawer Navigator та Stack Navigator.

Головний екран містить список новин, реалізований через FlatList. Кожен елемент списку включає зображення, заголовок та короткий опис. При натисканні відкривається екран деталей, де відображається повна інформація про новину. Дані передаються між екранами через параметри навігації.

Реалізовано Pull-to-Refresh, який оновлює список новин через імітацію мережевого запиту за допомогою setTimeout. Додано Infinite Scroll, що підвантажує нові елементи при досягненні кінця списку.

Для оптимізації продуктивності використано параметри initialNumToRender, maxToRenderPerBatch та windowSize. Також застосовано ListHeaderComponent, ListFooterComponent та ItemSeparatorComponent.

Окремо реалізовано екран контактів із використанням SectionList. Дані згруповані по секціях, кожна секція має заголовок і список елементів.

## Висновки

### 1. Чим відрізняється FlatList від ScrollView?

ScrollView відображає всі елементи одразу, що призводить до великого навантаження на пам’ять при великих обсягах даних. FlatList використовує віртуалізацію і рендерить лише видимі елементи, що значно покращує продуктивність.

### 2. Що таке віртуалізація списків?

Віртуалізація списків — це механізм, при якому в пам’яті знаходяться лише ті елементи, які відображаються на екрані або знаходяться поруч із видимою областю. Це дозволяє ефективно працювати з великими наборами даних.

### 3. Як здійснюється передача параметрів між екранами?

Параметри передаються через метод navigation.navigate із другим аргументом у вигляді об’єкта. На цільовому екрані вони отримуються через route.params.

### 4. Що таке вкладена навігація?

Вкладена навігація — це структура, у якій один навігатор містить інший. У даній роботі Drawer Navigator містить Stack Navigator, що дозволяє поєднувати різні типи навігації.

### 5. У яких випадках застосовується SectionList?

SectionList застосовується для відображення структурованих або згрупованих даних, коли елементи потрібно розділити на категорії, наприклад список контактів за типами або групами.
